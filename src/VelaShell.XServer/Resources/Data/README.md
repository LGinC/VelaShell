# 颜色名表

`rgb.txt` 取自 X.Org 的 [`rgb`](https://gitlab.freedesktop.org/xorg/app/rgb)(`master` 分支的 `rgb.txt`,原样未改),
是 X11 的颜色名数据库:约 750 项,含 `red1`–`red4` 这类编号变体与 `dark slate gray` 这类带空格的写法。
以**数据文件**随库分发(嵌入程序集),不是代码,不涉及净室规程(见 `../../AGENTS.md` 纪律 4)。
